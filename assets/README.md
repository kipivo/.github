# Kipivo brand assets

- [Logo](logo.svg) — Transparent SVG for desktop and mobile interfaces, navigation, and documentation.
- [Banner](banner.svg) — Wide SVG for GitHub and documentation headers.
- [App icon](icon.svg) — Square SVG with a solid dark background for generating platform icons. The artwork leaves room for system masks.

## App icon PNGs

Each export is square. Sizes are in pixels.

- Small icons: [16](icons/icon-16.png), [32](icons/icon-32.png), [48](icons/icon-48.png), [64](icons/icon-64.png)
- General purpose: [128](icons/icon-128.png), [192](icons/icon-192.png), [256](icons/icon-256.png)
- Distribution: [512](icons/icon-512.png) for [Google Play](https://developer.android.com/distribute/google-play/resources/icon-design-specifications) and [1024](icons/icon-1024.png) for [iOS, iPadOS, and macOS](https://developer.apple.com/design/human-interface-guidelines/app-icons)

For an [Android adaptive launcher icon](https://developer.android.com/develop/ui/views/launch/icon_design_adaptive), use the transparent logo as the foreground, size it to the safe zone, and set the background layer to `#121214`.
